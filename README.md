# Gigapixel Samurai downloads

Download the two integrations from the [download page](./index.html):

- **Browser right-click extension** — Chrome, Brave, or Edge. It fetches the image inside the logged-in page so private web images can be queued.
- **macOS Finder Quick Action** — right-click one or more local image files and send them to the queue.

The packages contain setup instructions and do not contain account passwords.
